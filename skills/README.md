# skills

## lenses

供随手调用的视角与动词。在和 AI 对话的任何时刻可以触发，把当下话题切换到一种新的看法上。

- `/theory` — 不要叙述代码做了什么，交付 Naur 意义上的"理论"：现实↔代码映射、为何如此构造、修改的自然性
- `/clear-explanation` — 解释一个概念、系统、工具或技术时切入的写法：先讲它解决的问题，再讲怎么解决；每句话要么推进理解，要么删掉
- `/communication-contract` — 我个人的沟通契约：向我解释时唯一目标是我能理解，判据是三个测试（能重推、能预测、能说出何时失效）；附带我的校准、理解导向文字的样子、以及一组失败反例
