## A Mathematician's Apology — G. H. Hardy, 1940

**移出日期**：2026-05-13
**原放置**：`canon/career/hardy_mathematicians_apology.md`（已删除）
**原状态**：在"推荐起点"四篇之一，"立命"分类内。

**移出原因**：

当前文件不是翻译，也不是 README 允许的"保留原文完整结构和信息量"的重写，而是对原书的压缩摘要。

具体证据：

1. **体量不对。** Hardy 原书正文约 90 页致密英文散文，保留信息量的中译通常在 6–8 万字。当前文件正文约 7,000–8,000 字，压缩比接近 10:1。
2. **章节骨架被保留，每节被压扁。** 原书 29 节，文件也是 29 节——序号一一对应；但每节只剩几段。§16（Euclid 素数证明 + 关于美的展开）原书展开数页，文件压到 10 行左右。
3. **第三人称口吻泄漏。** §11 中："我把数学分为两类：真正的数学（Hardy 称之为 'real' 数学）……"——Hardy 第一人称的自辩书里不可能出现"Hardy 称之为"。这证实文本是改写者在转述，不是 Hardy 本人在说。

这违反 README 两条明文规则：
- **不可以做**：摘要、总结、提炼、解读
- **重写**：保留原文完整结构和信息量；不删减，不压缩，不判断哪里重要哪里不重要

**读者反馈对准的对象**：

读者读完后的第一感受是"信息密度低，远不及 Hamming 那篇"。这一感受是准确的，但它对准的是这个压缩件，不是 Hardy。Hardy 这本书之所以八十多年后仍被反复引用，撑住它的恰恰是被压缩件剥掉的那 90%——那些看上去冗余、绕弯、可以删的部分，正是 README 内核"语言与压缩"在说的事。读者凭直觉感到了不对，回溯发现是文件本身违规，不是原作不行。

**今后**：

如未来出现合格的中译（按 README"重写"规则做的版本，6–8 万字量级，保留全部论证展开），或直接采用英文原文，可重新放入 canon。在那之前，与 Hamming 的对立张力暂时不出现在 canon 里。
